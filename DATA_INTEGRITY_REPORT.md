## Timezone calibration (critical finding)

The raw `ejtraderLabs/historical-data` source's `Date` column is **not UTC**. Empirically calibrated by cross-correlating against user-downloaded Dukascopy reference data with an explicit `Etc/UTC` timestamp:

- January 2013 (winter): best fit at raw − 2h (corr 0.99983, MAE $0.43)
- July 2013 (summer): best fit at raw − 3h (corr 0.99996, MAE $0.17)

This matches the standard EET/EEST broker-server-time convention (UTC+2 winter / UTC+3 summer, EU DST schedule). All data below has been converted to true UTC using the IANA zone `Europe/Bucharest` (zoneinfo, DST-aware) before any other processing. Verified: zero raw rows fall in a nonexistent (spring-forward) or ambiguous (fall-back) local time, so the conversion is exact with no silent shifting.

## Price scaling

Raw OHLC values are the true USD price × 100 (e.g. `155408.0` = $1554.08). Corrected in the loader before any check below runs.
