## 5. Market Regime

Method confirmed by the user 2026-08-25 (WP8 Q4): rolling ATR(14) percentile
for volatility, rolling Kaufman efficiency ratio for trend — both simple,
causal, non-ML measures, per the brief's own instruction.

**Calibration note, found here, fixed before any backtest.** The trend axis was
first built against the textbook 0.6 efficiency-ratio cutoff. Measured against
this development period it never fired once in 5.8 years (max observed 0.30) —
gold is too noisy intraday at 15m for that absolute number. It now reads the
ratio as a rolling percentile of its own trailing history instead (top quartile
= trending), the same shape as the volatility axis. See `config.py` and
`CHANGELOG.md`.
